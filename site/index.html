03 About

A reading room,
not a dashboard.

This atlas is the web index for Raunak Gupta’s Learn Android Bug Bounty repository. The report tree comes from B3nac’s Android-Reports-and-Resources; the library adds the practice apps, tools, videos and command references maintained in the repository.

Nothing is mirrored or rehosted. Every entry links to the original report, article, video or tool. Class summaries are editorial aids for scanning; titles, links and source labels come from the reading list and the field notes. No accounts, no analytics, no tracking. Just a static page and a data file.
